# PrimerListManager

遺伝子工学などのDNAを扱う研究者の多くが使用している[ApE (A Plasmid Editor)](https://jorgensen.biology.utah.edu/wayned/ape/) が受け付けるPrimer Listの形式に瞬時に変換するソフトです。
このソフトウェアを開くだけで、更新してくれます。また、Fowerd primerとReverse primerの色もカラーパレットで変更することができます。
[Release](https://github.com/n-thai0930/PrimerListManager/releases)でexeをDLしていただくと、GUI付きのソフトウェアをすぐにお使いになれます。
